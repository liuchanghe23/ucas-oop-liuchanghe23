# Assignment 1：UML 类图作业

本目录包含两道课后作业的 UML 类图：

1. `01_Library_Borrowing.puml`：图书馆借书、还书场景，包括大学生、书籍、图书馆管理员三个类。
2. `02_Automobile_Viewpoints.puml`：分别从厂家、车主、交通管理机构三个角度设计“汽车”类。

同时提供由 PlantUML 源文件导出的同名 SVG 和 PNG 图片，可直接查看或提交。`.puml` 文件是可编辑源文件。

## UML 符号说明

- `-` 表示私有属性（private）。
- `+` 表示公开方法（public）。
- `0..1` 表示零个或一个对象。
- `0..*` 表示零个或多个对象。
- `1..*` 表示一个或多个对象。
